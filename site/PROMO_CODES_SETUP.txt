Чтобы добавить код:
1. Открой promo-codes.js
2. Найди нужное казино.
3. Вместо "" впиши реальный промокод.

Пример:
"EpicStar": "YOURCODE"

После Commit GitHub Pages обновится автоматически.

Важно: добавляй только реальные действующие коды, которые партнёрка/казино разрешает использовать при регистрации.
