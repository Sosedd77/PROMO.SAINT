1. Создай бота через @BotFather.
2. Добавь бота администратором в @PROMO_OT_SAINT.
3. Скопируй .env.example в .env и вставь BOT_TOKEN.
4. При желании замени PROMO_CODE.
5. Установи: pip install -r requirements.txt
6. Запусти: python bot.py
7. В корневом site-config.js замени PromoSaintBonus_Bot на username бота без @.
8. Сайт загрузи на Tiiny.host заново.

Важно: BOT_TOKEN не вставлять в HTML/JS сайта. Сам бот должен работать отдельно на VPS/Render/Railway/другом Python-хостинге; Tiiny.host запускает только статический сайт.
